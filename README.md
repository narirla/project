# 🌍 MO:SI - 개인 간 여행 상품 거래 플랫폼

## 1. 프로젝트 개요

- 프로젝트명: MO:SI
- 기간: 2025.08.06 ~ 2025.08.29 
- 주제: 개인 간 여행 코스를 공유하고 거래할 수 있는 플랫폼 개발

---

## 2. 기획 배경

- 개인 맞춤형 여행 수요 증가
- 혼행, 반려동물 동반 여행 증가
- 기존 여행 플랫폼의 획일성 문제

👉 해결 방향  
→ 사용자 간 여행 코스를 직접 거래하는 플랫폼 구축   

---

## 3. 핵심 기능

### 👤 회원 관리
- 회원가입 / 로그인 / 로그아웃
- Spring Security 기반 인증/인가
- 구매자 ↔ 판매자 역할 전환
- 회원 정보 수정

---

### 🛍 상품 시스템
- 상품 등록 / 수정 / 삭제 / 상세조회
- 상품 검색 (자동완성, 검색기록 저장)
- Elasticsearch 기반 검색 구조

---

### 🛒 커머스 기능
- 장바구니 기능
- 주문 / 결제 기능
- 주문 내역 조회

---

### 💬 커뮤니티
- 게시글 CRUD
- 댓글 / 좋아요 / 신고 기능

---

### ⭐ 리뷰 시스템
- 상품 리뷰 등록 / 수정 / 삭제
- 구매자 / 판매자 리뷰 관리

---

### 📡 실시간 기능
- 1:1 실시간 채팅 (WebSocket 기반)
- 문의 목록 및 상태 관리

---

### 🗺 관광 정보
- 부산 맛집 정보 제공
- 교통약자 편의시설 정보 제공

---
